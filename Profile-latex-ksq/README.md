# Ksq LaTeX CV

This project uses the same semantic LaTeX layout, fonts, colors, spacing, header,
footer, and section components as the `Tairan He` CV project. The content has
been replaced with source-backed English information for Shuqi Ke.

## Where content goes

- `src/cv-data.tex`: name, contact links, document date, and title.
- `src/sections/`: profile, education, experience, research outputs, projects,
  and skills.
- `src/cv-style.sty`: shared visual system; normally do not edit this file.
- `src/main.tex`: section order.
- `input/resumesoft.html`: snapshot of the user-provided source page.
- `work/`: extracted facts, claim traceability, and final review notes.

No Tairan He resume claims remain in the content files. Publication venues,
author lists, dates, links, and metrics absent from the supplied source are not
invented.

## Build

Run from the project root:

```powershell
.\build.ps1
```

The final PDF is written to `output/pdf/ksq-cv.pdf`.
