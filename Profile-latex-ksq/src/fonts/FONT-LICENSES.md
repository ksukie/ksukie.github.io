# Bundled font licenses

The project vendors fixed font binaries because a current system-font lookup
would not reproduce the reference PDF deterministically.

- Source Sans Pro 3.006 (files retain the legacy `SourceSansPro` names): SIL
  Open Font License 1.1, Adobe Systems Incorporated. The exact files come from
  the LaTeX `sourcesanspro` v2.8 release.
- Roboto 1.00000: Apache License 2.0, Google.
- Font Awesome 4.x font: SIL Open Font License 1.1, Fonticons, Inc.
- Latin Modern Mono 2.004 and Latin Modern Math 1.959: GUST Font License.

The font binaries are redistributed unchanged. Refer to the respective
upstream projects for the complete license texts and copyright notices.
