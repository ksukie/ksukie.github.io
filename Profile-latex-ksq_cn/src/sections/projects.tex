\section{项目经历}

\cventryheading{VTLA}{}
\begin{itemize}
\cvprojectbodyfont
    \item 基于 LeRobot 0.5.2 构建实体机器人视触觉学习扩展栈，在保持上游 CLI/API 兼容的前提下，集成 AgileX Piper 主从臂、LTeach 触觉传感及数据采集、训练与评估流程。
    \item 支持 ACT、PI0/PI0.5 的触觉扩展与 DreamTacVLA；在 ACT 主干上引入力矩阵驱动的 Think--Dream--Act 分支，并以统一数据契约对齐机器人状态、RGB 观测、触觉力场与动作序列。
\end{itemize}

\cventryheading{TactiWeave-VP}{}
\begin{itemize}
\cvprojectbodyfont
    \item 面向短时触觉交互构建织物分类研究原型，将触觉压力图像序列与经标定的六维物理状态——三轴力、平面合力、摩擦系数和接触面积——联合建模。
    \item 使用单通道 ResNet-18 编码视觉特征、物理状态 MLP 编码六维状态，经逐帧融合、膨胀因果 TCN 与注意力池化完成时序分类。
\end{itemize}

\cventryheading{IsaacSim-Tactile4OpenWorld}{}
\begin{itemize}
\cvprojectbodyfont
    \item 基于 Isaac Sim / Isaac Lab 构建触觉接触研究平台，使用 UIPC/libuipc 建模刚体与可形变接触、柔性触觉膜形变及局部 Fx/Fy/Fz 力场重建。
    \item 将触觉 RGB、力场、机器人资产与实验任务纳入统一工作流，支持 Piper 与 Franka 的抓取、抬升、插入和滚动实验，并输出 RGB、元数据与 HDF5 研究数据。
\end{itemize}

\cventryheading{OpenFireAlert}{}
\begin{itemize}
\cvprojectbodyfont
    \item 构建面向野火与火烟监测的端到端边缘智能平台，整合 Jetson 上的 YOLO11/TensorRT 视觉推理、ESP32-S3 传感节点，以及 Spring Boot/MySQL 控制平面与 Web 控制台。
    \item 将相机、温湿度、烟雾与蜂鸣器信号纳入统一告警链路，通过按设备的抗抖动与冷却机制协同触发蜂鸣器、邮件和仪表盘告警。
\end{itemize}

\cventryheading{TactileFlowField}{}
\begin{itemize}
\cvprojectbodyfont
    \item 构建面向视觉触觉传感器的稠密光流学习与边缘部署工程，覆盖多版本模型管理、训练、PyTorch 流式推理及 ONNX/RKNN 转换。
    \item 以当前帧和初始参考帧预测稠密光流，支持 FP16 与基于训练后量化（PTQ）的 INT8 推理，以及 RV1126B 多路顺序推理、ROI 处理、基线标定和设备管理。
\end{itemize}

\cventryheading{EdgeVisTrack-RKNN}{}
\begin{itemize}
\cvprojectbodyfont
    \item 构建面向 RV1126B 的纯视觉多相机稀疏圆形标记点跟踪工程：通过区域 RGB 阈值、形态学闭运算和 Hough 圆检测完成首帧建模，随后在局部 ROI 内执行模板相关、亚像素定位与丢失回退。
    \item 提供 CPU、Fixed RKNN 与 Dynamic RKNN 三类后端；Fixed 使用模型内嵌的共享低秩模板，Dynamic 通过运行时系数保留各标记点的首帧外观差异。
\end{itemize}

\cventryheading{Vision Workbench}{}
\begin{itemize}
\cvprojectbodyfont
    \item 构建统一的 PySide6 桌面应用，通过模块化 Python API 提供七类计算机视觉工作流，覆盖传统图像处理、全景重建、YOLO 检测、分割与训练。
    \item 完成可选依赖隔离、184 个自动化测试函数、跨平台 Qt/无障碍检查，以及带版本门禁、SHA-256 校验、依赖指纹和回滚机制的 Wheel/Windows EXE 发布。
\end{itemize}

\cventryheading{AdaptiveUI-SKILL}{}
\begin{itemize}
\cvprojectbodyfont
    \item 设计两个显式调用的 Agent Skill，将 HTML/CSS、React、Vue、Svelte 和 Tailwind 项目的响应式 UI 工作转为审计、修复和验证流程。
    \item 实现零依赖 Python 分析器，提供 24 条稳定规则、严重度/置信度元数据、抑制机制、JSON Schema 输出、CI 阈值和 79 项自动化测试。
\end{itemize}

\cventryheading{AgentTools}{}
\begin{itemize}
\cvprojectbodyfont
    \item 构建只读 Codex 诊断工具，关联 PowerShell 配置、Conda Hook、Python 编码、Git 行尾、代理/TUN 状态和重连日志；脱敏凭据且避免系统修改。
    \item 提供跨平台 AGENTS.md 模板、任务上下文交接和运行时 Skill 清单，并遵循显式调用的插件契约。
\end{itemize}
